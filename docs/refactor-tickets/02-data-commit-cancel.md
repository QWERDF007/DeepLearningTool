# 02：统一数据操作取消与提交结果

**What to build（交付）:** 取消结果与真实提交状态一致，界面准确反映数据库。

**Blocked by（阻塞依赖）:** [01：修复数据并行异常丢失](01-data-worker-errors.md)

**Status:** ready-for-agent

此标签表示任务描述可领取；有阻塞依赖时须先完成前置。执行状态和验证证据仅维护在项目任务账本。

## 验收条件

- [ ] 提交前取消不留下提交结果；提交后取消保留真实已提交结果并更新投影。
- [ ] DataIO 与 Workflow 只有一个结果裁决来源，取消请求不被直接当成取消成功。
- [ ] 通过公开数据操作构造提交与回调之间的取消，重开核对数据库。
- [ ] 通过公开用例入口及真实下一层依赖先建立失败/约束测试，再实现；相关 Release 构建和 CTest 通过，必要真实资源验证有证据。

## 边界

只完成本票用例及其必要预重构，沿用现有模块接口。替换时删除废弃路径，不新增长期兼容双轨；不以文件行数或类数量作为拆分依据。
