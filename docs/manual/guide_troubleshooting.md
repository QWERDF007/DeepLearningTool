# 故障诊断

本章节汇总了在日常使用 DeepLearningTool 过程中可能遇到的典型故障症状、排查步骤及恢复建议。

返回 [手册首页](index.md) 或查看 [高级功能](guide_advanced.md)。

## 诊断排查一般流程

当软件出现异常现象或操作未达到预期时，建议遵循以下诊断步骤：

1. **观察系统通知栏 (InfoBar)**：应用顶部会弹出黄色警告或红色错误通知，阅读其简要提示信息。
2. **查验底部运行日志 (Footer Log)**：点击界面底栏右侧的日志图标，弹出 `LogDialog` 查看详细的底层运行日志与堆栈记录。
3. **查验后台任务进度 (Progress Center)**：点击底栏进度图标或顶栏“任务”按钮，排查是否有被挂起或超时的后台任务。

## 常见故障症状与处置方案

### 症状一：帮助文档无法打开

#### 表现 1：界面警告“帮助文档不可用，请重新安装完整程序。”
- **根本原因**：程序所在目录下的 `doc/index.html` 静态页面缺失、被意外删除或当前操作系统账户没有该文件的读取权限。
- **解决步骤**：
  1. 检查应用程序所在目录是否存在 `doc` 子文件夹，并确认其中包含 `index.html`。
  2. 如果文件丢失，请从完整官方发布包中重新解压或覆盖 `doc` 文件夹，确保安装完整性。

#### 表现 2：界面警告“无法打开帮助文档，请检查 HTML 文件的默认打开方式。”
- **根本原因**：系统接收到了打开本地 HTML 文件的请求，但操作系统没有为 `.html` 文件关联默认浏览器，或默认浏览器关联损坏被系统拒绝。
- **解决步骤**：
  1. 在 Windows“设置 → 应用 → 默认应用”中，确认“Web 浏览器”已设置为 Microsoft Edge、Google Chrome 或其他现代浏览器。
  2. 手动在文件管理器中右键任意 `.html` 文件，选择“打开方式 → 选择其他应用”，勾选“始终使用此应用打开 .html 文件”。

### 症状二：模型训练无法启动或报错退出

#### 表现 1：点击“开始训练”后瞬间报错或进程静默退出
- **可能原因 A：CUDA 与显卡驱动不匹配**
  - **排查方法**：在命令行执行 `nvidia-smi`，确认驱动支持的最高 CUDA 版本不低于程序附带 PyTorch 运行时的要求。
  - **解决建议**：前往 NVIDIA 官网下载并安装匹配显卡型号的最新 Game Ready 或 Studio/Enterprise 驱动。
- **可能原因 B：数据集中缺少有效样本**
  - **排查方法**：检查“图库”中是否将样本划入了训练集 (Train) 与验证集 (Val)。
  - **解决建议**：确保训练集与验证集中均包含至少一张带有有效标注的图像，且各类别实例数大于零。

#### 表现 2：训练进行数轮后突然报 `CUDA out of memory (OOM)` 显存溢出
- **根本原因**：所选图像输入尺寸 (Image Size) 过大或批大小 (Batch Size) 超出显卡可用物理显存。
- **解决建议**：
  1. 在“训练”配置面板中，将 **Batch Size** 调低（例如从 16 降至 8 或 4）。
  2. 若仍超显存，可适度将 **Image Size** 从 1024 调整为 640。
  3. 关闭其他占用独立显存的大型 3D 渲染软件或外部深度学习进程。

### 症状三：工件图像导入失败或缩略图全黑

- **表现**：点击导入后列表未见新增图像，或提示“格式非法 / 读取失败”。
- **排查与解决**：
  1. **检查图像格式**：当前支持的图片格式包括 `*.jpg`, `*.jpeg`, `*.png`, `*.bmp`, `*.webp`。不支持 CMYK 色彩空间的印刷图片或特种相机的未解码 RAW 格式。
  2. **检查文件损坏**：尝试使用系统自带图片查看器打开该图片，若系统查看器同样报错，则该文件在传输过程中已损坏。
  3. **检查磁盘访问权限**：若图像位于外部网络共享驱动器 (NAS) 或受保护系统文件夹，请将图像先拷贝至本地常规磁盘后再导入。

### 症状四：工程文件 (`.dlpro`) 打开失败

- **表现**：双击历史项目或选择文件打开时提示“打开项目失败 / 数据库损坏”。
- **排查与解决**：
  1. **排查进程多开冲突**：确认是否有另一个 DeepLearningTool 实例或外部 SQLite 编辑工具（如 Navicat/DBeaver）正独占打开该 `.dlpro` 文件。关闭冲突进程后重试。
  2. **排查只读属性**：检查 `.dlpro` 文件所在目录是否被设置为“只读”或存储介质写保护。
  3. **路径存在性**：若原工程所在目录已被重命名或物理移动，请使用“打开项目”按钮手动定位到新的工程文件路径。

---

### 症状五：AI 智能标注无响应或加载失败

- **表现**：点击“智能标注”点选工件后，掩膜长时间处于加载中状态，或提示智能标注未就绪。
- **排查与解决**：
  1. **等待基础权重加载**：首次启动智能标注时，后台正在通过 InferRT 运行时将 SAM 预测器模型权重加载至计算设备，通常需要 2~5 秒初始载入时间。
  2. **核对模型文件与运行时配置**：智能标注依赖全局设置中配置的 SAM 模型文件与 InferRT 运行时。若配置的模型路径指向不存在的文件，或指定的运行时环境与当前显卡驱动不兼容，加载将无法完成。
  3. **查验日志诊断信息**：点击底栏右侧日志图标打开日志面板，检索消息关键词“`加载智能标注`”或“`智能标注`”。若出现“`加载智能标注模型失败`”或预测器加载异常，请依据日志中打印的实际模型路径与具体错误信息修正配置路径或显卡驱动环境。
