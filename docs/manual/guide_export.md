# 数据与模型导出

本章节介绍 DeepLearningTool 中当前支持的数据集标准化导出、模型训练产物保存位置以及功能边界说明。

返回 [手册首页](index.md) 或查看 [模型评估](guide_evaluation.md)。

## 功能边界与当前支持状态

在当前版本中，软件顶层导航栏包含“导出”标签页，但该页面目前为规划中的预留入口，尚未接入独立视图组件。实际可用的导出与模型交付能力分别在**图库模块**与**模型训练输出目录**中提供：

| 交付产物 | 当前操作路径 | 输出内容与格式 |
| :--- | :--- | :--- |
| **已标注数据集导出** | [图库](guide_gallery.md) → 右键数据集选择“导出” | 标准化 COCO / LabelMe JSON、单通道或二值 Mask 掩膜、分类 Folder 目录 |
| **模型训练权重** | [模型训练](guide_training.md) 结束后自动生成 | `models/<模型名>/train/weights/`（异常检测为 `model.ckpt`，YOLO 为 `best.pt`/`last.pt`）与 `models/<模型名>/train/logs/train.log` 日志 |
| **顶层“导出”视图** | 顶部导航栏第 7 个标签（规划中） | *当前版本未接入独立交互页面，请使用上述两个已实现路径* |

```{important}
请勿依赖顶栏未实现的“导出”空白页面。若需将数据提供给外部训练框架，请使用图库中的数据集导出；若需获取训练好的模型部署文件，请直接在工程目录下的 `models/` 文件夹提取生成的最佳权重。
```

## 数据集标准化导出流程

当工件样本已完成精细标注并经过[标注检查](guide_inspection.md)质量复核后，可将其导出为通用格式以用于跨系统协同：

1. 打开项目，切换至 **图库** 页面。
2. 在左侧数据集树中右键点击选中的数据集，选择 **导出**，系统调出 `DatasetDataIODialog` 弹窗。
3. **选择数据源**：勾选需导出的数据集划分（如全部训练集与验证集）。
4. **选择目标格式**：
   - **COCO 格式**：输出包含标准 `annotations`、`images`、`categories` 结构的单个 JSON 文件，适合目标检测与实例分割。
   - **LabelMe 格式**：为每张图像输出对应的同名 `.json` 矢量轮廓文件。
   - **Mask 掩膜格式**：适用于语义分割与异常检测，输出与原图尺寸严格一致的单通道 PNG 掩膜图像。默认二值模式下前景像素固定为 255（背景为 0）；若选择“按类别”模式导出，像素灰度值使用类别顺序连续编号加一（1, 2, 3...，支持至 255 类，非数据库内部 ID），并在导出根目录生成包含像素值、类别名称与颜色映射关系的 `classes.json` 元数据文件。
   - **Folder 格式**：适用于图像分类，按类别名分目录归类存放图像。
5. **指定输出目录**：选择本地硬盘存储文件夹，点击 **导出**。
6. 系统在后台执行序列化写入，导出完成后可在目标文件夹中直接查验生成的图像与标注文件。

## 模型权重与工程文件提取

在模型训练完成后，所有模型资产均按照规范化目录保存在项目工程文件夹中：

```text
<项目存储目录>/
├── <项目名>.dlpro                  # SQLite 核心工程数据库
├── models/                         # 模型输出主目录
│   └── <模型名>/                   # 对应模型专属目录
│       ├── model.db                # 模型元数据与任务记录数据库
│       ├── train/                  # 训练产物根目录
│       │   ├── weights/
│       │   │   ├── model.ckpt      # 异常检测模型权重（PatchCore / Anomalib）
│       │   │   ├── best.pt         # 目标检测与分割最优权重（YOLO）
│       │   │   └── last.pt         # 最后一轮完整训练检查点（YOLO）
│       │   └── logs/
│       │       └── train.log       # 训练控制台详细执行日志
│       └── test/                   # 测试任务根目录
└── images/                         # 样本图片存储目录
```

用户可根据模型类型直接将对应的权重文件（如异常检测使用 `model.ckpt`，检测分割模型使用 `best.pt`）复制到产线工控机或算法推理端，加载用于工业相机的在线实时质检。
