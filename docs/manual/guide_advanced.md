# 高级功能

本章节介绍 DeepLearningTool 中已实现的高级辅助功能，包括以图搜图、区域检索、图像聚类、少样本学习、统计报表、任务中心与全局设置。

返回 [手册首页](index.md) 或查看 [故障诊断](guide_troubleshooting.md)。

## 高级功能架构概述

DeepLearningTool 不仅支持常规的有监督标注和模型训练，还内嵌了基于深度特征表示向量的工业视觉辅助分析工具集。

![高级功能流程](_images/feature_search.svg)

系统内置专用特征提取骨干网络与高性能向量检索索引库（FAISS），可在工件图像导入后异步完成全图与局部区域的深度特征表征嵌入，为快速定位瑕疵、辅助分类和少样本适应提供强力支撑。

## 1. 图像搜索 (Image Search)

当面对海量工件样本，需要找出与某张特定不良品或工件外观高度相近的图像时：

1. 在 **图库 (GalleryView)** 中右键单击目标工件图像缩略图，在右键上下文菜单中选择 **图像搜索**。
2. 弹出 `ImageSearchDialog`（图像搜索对话框），在对话框中勾选需要检索的目标数据集范围。
3. 点击 **开始搜索** 启动检索，对话框随后自动关闭并由后台异步执行特征比对。
4. 检索命中的相似图像直接过滤呈现在当前 **图库 (GalleryView)** 缩略图网格中，支持在图库中直接批量查看、加选或分配类别（图库界面基于命中的图像 ID 范围执行动态筛选展示，不涉及额外相似度数值展示契约）。

## 2. 区域检索 (Region / ROI Search)

当工件表面仅有极其细微的局部瑕疵（如崩角、细线刮擦），全图相似度无法体现局部异常，需要跨数据集挖掘相似缺陷并自动生成标注时：

1. 在标注工作区画布中，使用选中模式 (F1) 单击选中已有的单个标注实例（矩形或多边形图元）。
2. 在画布上右键单击该标注图元弹出上下文菜单，进入 **标注搜索** 子菜单：
   - **已有标注搜索**：在历史已标注样本切片中检索相似图元。
   - **区域检索并生成标注**：点击打开 `RegionSearchDialog`（区域检索对话框）。
3. 在区域检索对话框中，勾选目标检索数据集，设定相似度匹配阈值。
4. 点击 **开始检索**，系统提取该标注局部的细粒度特征向量，在目标图像集中执行高精度特征匹配。
5. 检索完成后支持直接在匹配到的工件位置上自动生成新的标注实例并持久化落库，极大提升相似罕见缺陷的汇聚标注效率。

## 3. 图像聚类与 ROI 聚类 (Clustering)

在建标初期或数据治理过程中，系统提供无监督聚类能力以加速样本归类与缺陷细分：

### 图像聚类 (Image Clustering)
针对整幅图像的全局表征进行聚类，适合对海量无序的未分类工件图像进行初筛与结构化归集：
1. 打开 **图像聚类** 对话框（可在软件设置中配置 HDBSCAN 聚类的邻居搜索方式、距离度量、导出噪声簇开关及输出方式等参数）。
2. 在对话框中勾选待聚类的源数据集。
3. 点击 **开始聚类**，系统提取图像全局特征并执行聚类分析。
4. **生成目标数据集**：聚类完成后，系统根据配置的输出方式（默认为“移动”，也可配置为“复制”）在图库中自动创建按簇命名的新数据集（命名格式为 `<源数据集名>-<簇编号>`；若启用了“导出噪声簇”，离群噪声样本将归入 `<源数据集名>-noise`，未启用则自动跳过噪声样本），并将图像划分归类至对应数据集。

### ROI 聚类 (ROI Clustering)
针对已有标注实例（图元局部切片）的细粒度特征进行聚类，适合在同类或跨类标注中发掘细分缺陷模式或一致性亚类：
1. 打开 **ROI 聚类** 对话框（可在软件设置中配置簇参数、邻居搜索、距离度量及包含噪声开关等）。
2. 在对话框中勾选待分析的数据集范围及其特定标注类别。
3. 点击 **开始聚类**，系统提取各个标注实例区域的局部特征进行聚类。
4. **自动赋予聚类标签 (Tag)**：聚类完成后，系统保持原始图像与数据集归属不变，自动按类别和簇编号生成标签（命名格式为 `<类别名>-<簇编号>`；仅在设置中启用“包含噪声”时才会为噪声样本生成并赋予 `<类别名>-noise`，默认关闭时跳过噪声样本），并直接赋予到对应的标注实例上，便于后续按标签精细筛选与复核。

## 4. 少样本迁移学习 (Few-Shot Learning)

在工业小批量、多品种快速转产换线场景下，新缺陷样本极其匮乏（如仅有 3~5 张标样），传统深度学习难以有效收敛：

1. **前提条件与依赖配置**：
   - **项目任务类型**：当前工程需为**目标检测 (Detection)**、**实例分割 (Segmentation)** 或 **异常检测 (AnomalyDetection)** 项目。
   - **依赖项准备**：在“软件设置”中已配置有效的 **Python 环境目录**，且在小样本学习设置中已指定合法的 **SAM2 权重文件 (.pt)** 与对应的 **SAM2 架构配置**。
   - **数据准备**：已导入样本并创建数据集与标签类别，确保至少勾选一个训练数据集、一个测试数据集以及至少一个有效标注类别。
2. **操作流程**：
   - 打开 **小样本学习** 对话框 (`FewShotLearningDialog`)。
   - 依次勾选参与少样本学习的训练数据集、验证数据集、测试数据集以及目标标注类别。
   - 点击 **启动** 发起任务，系统校验通过后创建 `FS-SAM2` 模型管线，通过后台调度引擎执行少样本适应与特征提示引导，实现极少先验样本下的快速精准检测与缺陷分割。

## 5. 类别统计报表 (Statistics)

点击顶部 Header 区域的 **统计** 按钮（折线柱状图图标）：
- **类别分布柱状图**：直观展示训练集、验证集和测试集中各缺陷类别的实例数量与占比。
- **标注样本均衡度**：自动提示是否存在极端样本不平衡（长尾效应），辅助质检工程师有针对性地补充稀缺类别样本。

## 6. 任务中心 (Task Center)

点击顶部 Header 区域的 **任务** 按钮：
- 弹出 `TaskCenterWindow` 任务管理中心。
- 集中查看正在后台运行的训练任务、特征向量异步提取任务与批量导入/导出操作。
- 支持查看每个任务的耗时、完成百分比、执行状态（运行中、排队中、已完成、失败），并可强制终止异常超时的后台作业。

## 7. 系统设置 (Settings)

点击右上角顶栏的 **设置** 按钮（齿轮图标）调出参数配置对话框，系统设置集中由 YAML 配置项驱动并持久化于本地数据库：

- **软件设置 (SoftwareSetting)**：
  - **最近项目数量**：配置启动欢迎页与文件菜单中保留的最近打开项目条目上限（范围 1～50 条，默认 10 条）。
  - **自动保存机制**：支持配置“启用自动保存”开关及“自动保存间隔”（范围 30～3600 秒，默认 300 秒），防止意外断电或程序异常退出造成工作成果丢失。
  - **Python 环境目录**：指定外部独立训练引擎和脚本运行所使用的 Python 环境根目录路径。
- **界面设置 (UISettings)**：
  - **图像亮度与对比度**：全局微调工作区图像画布的基础显示亮度与对比度（范围 -1.0～1.0），增强暗场或高反光工业图像的可视度（仅影响显示，不修改原始图像数据）。
- **算法与特征模块参数**：
  - 支持分别配置图像检索、区域检索、聚类分析、少样本学习与智能标注各模块的默认推理批大小、特征维度与阈值参数。
- **快捷键说明**：
  - 标注类别快捷键由当前项目类别列表配置驱动；界面交互遵循通用标准快捷键（如 Esc 关闭菜单与弹窗），软件未提供全局按键自定义映射面板。
