# 02: 项目与图库上手流程

**What to build:** 新用户从应用打开本地手册，完成必要环境准备、创建或打开项目、导入图像并组织图库；能通过功能参考理解保存结果及再次打开项目的方式。

**Blocked by:** [01: 最小离线帮助闭环](01-offline-help-tracer.md).

**Status:** completed

**Spec:** [实施决策](../HELP_DOCUMENTATION_SPEC.md#implementation-decisions) D1、D3、D4、D8、D9；[测试决策](../HELP_DOCUMENTATION_SPEC.md#testing-decisions) T3—T7；用户故事 10—12、20、21。复用 01 的阅读与发布闭环，不修改帮助接口或独立构建第二套站点。

- [x] 快速上手只说明当前环境和安装实际需要的准备，开发构建细节不进入产品教程。
- [x] 说明项目、图库及相关最少必要概念，项目创建、打开、保存位置和重新打开流程与实际程序一致。
- [x] 说明实际支持的图片导入和图库组织操作，前提、操作与结果清楚，不沿用参考项目的存储格式或导入语义。
- [x] 用户可沿完整任务从项目开始到得到可用图库；功能参考可直接定位项目或图库操作，共用概念只维护一份。
- [x] 使用真实项目和图像资源复现创建、导入、组织及重新打开，检查持久化结果，按照 T5 核对内容和截图。
- [x] 仅对实际可复现的限制和失败提供说明，不把未经验证的中文路径限制或历史行为写入手册。
- [x] 章节接入唯一导航，交叉引用目标真实存在；不依赖后续票据的页面，不添加未交付章节占位。
- [x] 截图与图片均来自当前产品并本地引用，未引入远程资源或外部工程依赖。
- [x] 在实际发布包中从帮助菜单进入，断网检索项目和图库相关中文词、跳转并查看图片，Edge 与 Chrome 验证通过。
- [x] 内容更新进入既有构建、安装和打包链路，相关链接、锚点及资源检查通过；帮助入口定向回归无异常。
- [x] 按 T7 记录真实操作和发布阅读证据；不把文档写完等同于功能验证完成。
