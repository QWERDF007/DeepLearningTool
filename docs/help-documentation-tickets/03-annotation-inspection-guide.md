# 03: 标注与检查操作流程

**What to build:** 用户通过应用中的离线手册，对已有真实图库执行当前支持的标注和检查操作，识别并修正可观察的问题，再确认修改结果。

**Blocked by:** [01: 最小离线帮助闭环](01-offline-help-tracer.md).

**Status:** completed

**Spec:** [实施决策](../HELP_DOCUMENTATION_SPEC.md#implementation-decisions) D1、D3、D4、D8、D9；[测试决策](../HELP_DOCUMENTATION_SPEC.md#testing-decisions) T3—T7；用户故事 13、14、20、21。独立使用有效图库作为操作前提，不以 02 的章节交付作为阻塞项。

- [x] 根据实际支持的标注方式组织任务，说明类别或标签等必要前提以及当前有效的交互，不扩写未实现的标注能力。
- [x] 标注、编辑、保存及结果查看流程与真实产品一致，文字和截图可以让用户按步骤操作。
- [x] 检查章节说明如何定位问题、进行修正和确认结果，不将检查页描述成产品未提供的自动质检能力。
- [x] 使用真实图像及标注资源，完成至少一条标注到检查再到修正的闭环，确认保存与重新查看的实际结果。
- [x] 本领域的前提和概念不重复维护；需要其他领域知识时链接已存在的内容，未交付章节不形成断链。
- [x] 图例、类别名称、工具提示及快捷操作与当前界面一致，未验证的操作不写为可用能力。
- [x] 章节进入唯一导航和搜索索引，不调整帮助公开接口或复制文档构建配置。
- [x] 本地截图与交叉引用通过完整性检查，所有阅读所需资源均可断网使用。
- [x] 从实际发布包的帮助菜单打开，在 Edge 与 Chrome 断网搜索标注、检查及章节中的业务词，结果跳转和图片显示正常。
- [x] 执行相关站点和帮助入口定向回归，按 T7 记录真实标注、修正和离线阅读证据。
