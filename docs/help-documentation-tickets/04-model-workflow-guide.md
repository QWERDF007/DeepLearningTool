# 04: 训练、评估与导出流程

**What to build:** 用户从离线手册了解模型任务的前提、实际可执行步骤和结果，使用已准备的数据完成本项目支持的训练、评估及导出流程，并能识别相关功能的真实边界。

**Blocked by:** [01: 最小离线帮助闭环](01-offline-help-tracer.md).

**Status:** completed

**Spec:** [实施决策](../HELP_DOCUMENTATION_SPEC.md#implementation-decisions) D1、D3、D4、D8、D9；[测试决策](../HELP_DOCUMENTATION_SPEC.md#testing-decisions) T3—T7；用户故事 15—17、20、21。以有效数据和模型资源独立验收，不等待 02、03 的文档，也不修改业务功能来满足教程。

- [x] 说明用户实际需要准备的数据、模型与运行环境，不把文档构建环境和训练环境混为一体。
- [x] 至少对一种当前可运行的模型任务提供完整操作路径，核对启动、状态查看和结果入口，不承诺未经验证的模型范围。
- [x] 评估说明覆盖实际输入、执行方式和可观察结果，指标或可视化解释与当前实现一致。
- [x] 核对真实导出能力，说明可用操作的前提和结果；若界面存在未实现能力，准确说明边界，不虚构流程、不把补齐业务功能加入本票据。
- [x] 使用真实资源执行支持的训练、评估和导出操作；没有可执行导出能力时提供实现核对证据，并将验收限定为准确表达这一边界。
- [x] 完整参数定义不在手册手写维护；操作所需解释引用唯一事实源或已经存在的共用说明。
- [x] 截图、任务状态、结果名称及支持限制经实际运行核对，未验证限制不作为产品要求写入。
- [x] 章节进入唯一导航和索引，所有交叉引用目标存在，不依赖尚未交付的其他票据页面。
- [x] 在 Edge 与 Chrome 的实际发布包中断网查找训练、评估、导出及正文实际涉及的业务词，跳转、图片和主题正常。
- [x] 相关站点资源检查与帮助入口定向回归通过，按 T7 记录所用资源、实际任务结果和离线阅读证据。
